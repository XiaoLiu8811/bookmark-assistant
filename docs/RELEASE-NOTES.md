# Release notes

## 0.1.0 (unreleased)

First version: your bookmarks, before the web.

- Search Google as usual. Up to 3 matching bookmarks appear above the results, with their folder path. Matching uses the title, the folder names and the web address, and tolerates typos.
- No match, no panel.
- An amber **ON** badge on the toolbar icon shows the mode is on. Click the icon to turn it off or on; the setting is kept across restarts.
- **Hide** dismisses the panel for one search.
- Hover over the toolbar icon to see how many panels were shown and how many bookmarks you opened from them.
- Nothing leaves your device: no server, no account, and the extension is blocked from making network requests.
